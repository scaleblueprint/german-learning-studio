# German Studio visual identity

This app belongs to AmberTheory, but has a distinct warm learning atmosphere instead of repeating the cream/green palettes of other education apps.

## Canonical AmberTheory logo

- Use the full `dist/ambertheory-lockup.jpg` JPEG in the header, sourced without alteration from `scaleblueprint/form-and-wonder/public/ambertheory-lockup.jpg`.
- This is required by `scaleblueprint/form-and-wonder/AMBERTHEORY-BRAND-RULE.md`; never replace it with the standalone layered lens symbol, `AT` initials, or a text-only wordmark.
- The header behind it stays near-black (`#171717`) to merge visually with the source artwork.
- The separate **German Studio** label identifies this learning product without altering the parent's logo.

## Learning palette

| Purpose | Color |
| --- | --- |
| Near-black brand header | `#171717` |
| Deep plum action/structure | `#72344b` |
| Warm amber current step and main learning CTA | `#ffc76b` |
| Coral active practice/exam invitation | `#df6252` |
| Calm ivory background | `#fff9f2` |
| Earned completion and success | `#167e61` |

Type: Space Grotesk for interface headings, DM Sans for reading, Fraunces where German phrases benefit from editorial styling.

## Guardrails

- Preserve Learning / Teacher Studio workspaces and their contextual section menus.
- Keep all progress indicators grounded in saved lesson completions or attempts. Existing illustrative teacher/sample indicators must remain clearly labelled.
- Keep available/disabled exam levels visibly distinct. Progress green communicates completion; amber communicates the next possible step.
- Maintain contrast, touch-target sizes, responsive layout, keyboard focus indicators and reduced-motion support.
- All visual overrides belong in `dist/amber-theme.css`; the substantive lesson, practice, teacher and exam content is maintained separately.
