# Teacher Exam Studio — page requirements and review workflow

Teacher Studio contains an Exam Coaching section above the existing Session and Experience studios. It is an extension of the current teacher workspace, not a new role or login flow.

## Question authoring

1. A teacher may create an original A1 listening or reading multiple-choice practice question for Goethe or telc.
2. Required fields: scenario, German audio script or passage, question, exactly three candidate answers, correct-answer index, explanation.
3. Drafts remain teacher-only. **Publish** makes an item available to the demo learner's skill practice and future mini-mocks.
4. The teacher can edit, publish or unpublish authored items; published changes affect newly started attempts only. Each attempt snapshots its own question list and answer key.
5. Publishing represents that the teacher has reviewed the item; the prototype does not provide multi-person approvals.

## Response review

1. Writing and speaking-rehearsal notes from completed practice attempts enter the teacher review panel.
2. Teachers see the original task, response and success checklist, then provide a qualitative comment and a 1–5 internal practice rating.
3. Save feedback to browser-local storage and display it on the learner's corresponding attempt result.
4. Never equate the internal practice rating with a Goethe/telc examination grade.
5. A blank or very short comment is rejected with an actionable message.

## Before a real pilot

- Conduct a teacher-led language, pedagogy and rubric review of every seeded and teacher-authored item.
- Add authenticated learners and educators, consent, roles, an audited content approval workflow, secure submissions and durable database storage.
- Record skill-aligned progress per person rather than pretending the fictional demonstration cohort is real.
- Support actual speaking submissions only with clear consent and an appropriate secure storage policy.
